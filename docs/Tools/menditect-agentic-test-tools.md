# Menditect agentic test tools

## Purpose

Use the Menditect agentic test tools to quickly setup your local LLM workspace. It is a plug-and-play Customer Workspace Template for building, designing, and running automated Mendix tests using AI Agents (such as Cursor, Claude Code, GitHub Copilot / Codex, Antigravity / Gemini, Cline) powered by Menditect Test Automation (MTA).
