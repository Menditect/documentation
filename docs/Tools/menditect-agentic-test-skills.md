# Menditect agentic test skills

## Purpose

Use the Menditect agentic test skills Mendix module to make sure your App is up-to-date with the latest Skills for Test Design and Test Execution using a conversational AI.

**This module is required to connect any LLM to MTA. **

## Supported Versions

The latest supported version is available in the Mendix marketplace.

## Installation instructions

- Upgrade your Mendix App to runtime version 11.12 or higher.
- Download the Menditect agentic test skills module from https://marketplace.mendix.com/link/component/305457
- Follow the instructions here: https://github.com/Menditect/agentic-test-skills#menditect-agentic-test-automation-mta-skills

## Update instructions

Replace the module in the Mendix Project if there is a newer version available for the Mendix Runtime.

## Dependencies

None.
